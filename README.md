## 🔬 What I'm Building Here

This GitHub is where I write real code from the domains I lead. Not toy examples — production-adjacent implementations that reflect how I think about systems.

### 📘 Stanford CS336 — Language Modeling from Scratch *(in progress)*

Self-studying Percy Liang & Tatsunori Hashimoto's graduate course on building LLMs from first principles. Each assignment ships as its own repo:

- **`cs336-a1-transformer`** — BPE tokenizer + transformer + AdamW optimizer, all from scratch in PyTorch. No `nn.TransformerEncoder` shortcuts.
- **`cs336-a2-flashattention`** — FlashAttention2 forward + backward kernel in Triton. Benchmarked against PyTorch attention for MFU and memory footprint.
- **`cs336-a3-scaling`** — Chinchilla scaling law experiments: fit power laws, predict compute-optimal N and D at different FLOP budgets.
- **`cs336-a4-data`** — Web-scale data pipeline: Common Crawl quality filters + MinHash deduplication. Train on clean vs. dirty corpus and measure perplexity gap.
- **`cs336-a5-alignment`** — SFT → reward model → PPO → DPO. Side-by-side benchmark of RLHF vs. DPO on instruction following.
